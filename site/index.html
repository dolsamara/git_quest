What is Git?

Git is a distributed version control system that helps developers track changes in their code. It allows multiple people to collaborate on projects, manage versions, and safely experiment without losing work.

Why Use Git?

  • 📌 Track code history
  • 👥 Collaborate with teams
  • 🔄 Branch and merge easily
  • 💾 Backup your work
