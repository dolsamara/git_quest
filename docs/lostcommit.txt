Крок 8. Загублений комміт

Мандруйте назад на свою гілку 
    git checkout feature/ваша-назва

Тепер віднайти що тут було втрачено
👉 Спробуй команду:
    git reflog
💡 Вона показує “історію рухів HEAD”
👉 Знайди підозрілий коміт і виконай:
    git checkout <commit-hash>
👉 Щоб повернути зміни:
    git cherry-pick <commit-hash>

Очікуваний результат
    знаходимо загублений коміт
    відновлює його
    бачимо, що Git = не просто “save”, а система історії
